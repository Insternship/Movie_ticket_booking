# Movie Ticket Booking

A full-stack movie ticket booking application where users can view movie shows, select available seats, and confirm bookings.

## Features

- View available movie shows
- View available seat count
- Seat selection interface
- Booked seats cannot be selected
- Booking confirmation
- Ticket total calculation
- Ticket price stored at booking time
- CRUD operations for movies and shows
- Validation and error handling
- Loading, error, and empty states
- Concurrency protection against double booking

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Axios

### Backend
- Node.js
- Express
- MongoDB
- Mongoose
